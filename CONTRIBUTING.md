# Contributing to Mimo

Mimo is a live consumer product. Changes should protect speed, trust and the shared-room experience.

## Before opening a pull request

1. Keep the main Create → Host → Play → Prove → Drop flow complete.
2. Never trust client-submitted scores, timers, eligibility or payment status.
3. Never claim that money is funded, locked, escrowed or confirmed without evidence.
4. Keep free participation possible unless the event creator explicitly selects another access rule.
5. Use constrained social interactions rather than unrestricted chat.
6. Test small mobile screens and reduced-motion behavior.
7. Run the verification commands from the README.

Use focused commits and explain the user problem solved by the change.
