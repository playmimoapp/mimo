# Mimo brand system

## Official logo

The Mimo mark is a continuous blue ribbon drawn into a friendly lowercase “m”. The two arches echo the mascot’s loop silhouette. The rising tail gives it movement; the yellow dot is the host light that signals a room is ready.

- `public/mimo-logo.svg` — primary horizontal logo.
- `public/mimo-mark.svg` — standalone app and social mark.
- `public/favicon.svg` — browser icon using the standalone mark.

## Usage

- Use the horizontal logo in product navigation and formal brand material.
- Use the mark alone only when the Mimo name is already obvious or space is very small.
- Keep clear space around the logo equal to the yellow dot’s diameter.
- Do not recolour, stretch, rotate, glow, outline, or place the logo on a busy image.
- The mascot is a character and host. It does not replace the official logo.
